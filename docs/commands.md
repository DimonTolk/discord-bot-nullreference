# Команды, права и лимиты

Размещение — Cloudflare Workers; взаимодействие через Discord HTTP Interactions. Фоновые проверки выполняются каждые 10 минут. Семья/полиция определяется существующей Discord-ролью. Организатор один раз
привязывает роли через `/family_role`. Команды `/join` нет. Привязки хранятся
в PostgreSQL отдельно для каждого сервера/сезона и действуют без перезапуска.

Нужна **ровно одна** из настроенных игровых ролей. Другие Discord-роли не мешают.
Без игровой роли доступны `/start`, `/help`, `/leaderboard`, `/status`;
организатор может выполнять административные команды и без роли семьи.
Общие ответы (/start, /help, /leaderboard, /status, запуск/участие/итог операции, /raid, заявка/итог/доход района) видны в канале. Личный кошелёк, переводы, конверты, расследования, решения по облаве и административные ответы остаются приватными. Новости публикуются в выбранном канале.

Первый игрок стороны, использовавший команду с проверкой членства, становится её
главой, если глава ещё не назначен. Организатор может назначить другого через
`/leader_set`. Глава — игровое назначение в БД, отдельная Discord-роль для него
пока не используется. Наличие прав администратора не заменяет полномочия главы
в игровых командах.

Все недельные лимиты считаются с понедельника 00:00 UTC, суточные — с 00:00 UTC.
«Без лимита» означает отсутствие игрового ограничения частоты; ограничения API
Discord продолжают действовать. Неудачная команда не тратит ресурс или попытку.

## Общие команды

| Команда | Кто может | Эффект и ограничения |
| --- | --- | --- |
| `/start` | Все | Приветствие; без игрового лимита |
| `/help` | Все | Краткая справка; без лимита |
| `/leaderboard` | Все | Рейтинг по всему заработанному влиянию; без лимита |
| `/status` | Все | Районы, сроки, открытые операции; без лимита |
| `/profile` | Любой с игровой ролью | Личный кошелёк, касса и глава стороны; без лимита |
| `/inbox` | Любой с игровой ролью | Адресованные конверты/собственные предложения и входящие передачи для стороны; без лимита |
| `/work` | Любой с игровой ролью, включая полицию | 20–30 личных денег; 1 раз в сутки, максимум 3 раза в неделю **на человека** |
| `/donate amount` | Любой с игровой ролью | Перевод в кассу своей текущей стороны; без лимита числа переводов, 1–10000 за команду, в пределах кошелька |

## Операции «Ночная смена»

| Команда | Кто может | Эффект |
| --- | --- | --- |
| `/operation_catalog risk` | Все | 6 описаний грузов для low / normal / high (18 всего) |
| `/operation_start risk route [cargo] [prepared]` | Глава преступной семьи | 24 часа на 3–6 участников; скрытый маршрут port / station / highway; один старт семьи в неделю; 2 улики полиции; подготовка за 40 необязательна |
| `/operation_join operation` | Член семьи | Присоединиться до срока; затем обязательно выбрать задачу |
| `/operation_board operation` | Семья или полиция | Личный пульт с кнопками; маршрут другой стороны и её решение скрыты |
| `/operation_task operation task` | Участник | Разведка scout / документы papers / погрузка load; одна неизменяемая задача |
| `/operation_resolve operation` | Семья или назначенный полицейский | После сбора: без совпавшего заслона груз проходит, иначе 6-часовой раунд; после обоих решений итог сразу |
| `/raid_tactic operation tactic` | Назначенный полицейский | inspect / pursue / block, один выбор в раунде |

Успех (касса / каждому / влияние): low 40/15/2, normal 70/25/4, high 110/35/6. При перехвате база 75/60/45%, +5 п.п. за вид подготовки, +5 за участника сверх третьего, +10 за подготовку за 40; пределы 10–95%. Ложный конвой за 20: +20/−15/+5 против досмотра/погони/блокады; бесплатный прорыв: +10/−5/−20. Сдача груза без штрафов и дохода, возвращает 20 при оплаченной подготовке.

При конфискации нет оплаты, потери влияния/новые улики: low 0/0, normal 1/1, high 2/2; риск ранения одного участника на сутки: 0/15/30%. Полиции за перехват: уход груза 1 влияния и 10 в кассу, конфискация/сдача 3 и 30. Нет награды за само выставление заслона. Старые открытые дела сохраняют старые правила: `/help topic:legacy`. Новые: `/help topic:operations` и `/help topic:intercept`.

## Полиция и взятки

| Команда | Кто может | Эффект и ограничения |
| --- | --- | --- |
| `/patrol family` | Действующий полицейский | Шанс 60% на +1 улику против выбранной преступной семьи без дела или облавы; 1 раз в сутки, максимум 3 раза в неделю на полицейского (UTC), отдельно от работы и проверок отдела; ответ личный |
| `/investigate family` | Любой действующий полицейский | Проверка открытого дела без назначенной облавы, шанс 60% на +1 улику; **3 проверки на весь отдел в неделю** |
| `/raid operation` | Любой действующий полицейский | До окончания набора: 2 улики и route для «Ночной смены», 3 улики для старого дела. Одна облава на дело и не чаще раза за 7 суток против одной семьи; отдельного недельного лимита облав нет |
| `/raid_response operation decision` | Глава затронутой семьи | «Ночная смена»: в 6-часовом раунде сдать груз / ложный конвой за 20 / прорыв. Старое дело: отмена / маршрут за 40 / продолжение |
| `/bribe_offer operation amount` | Любой член затронутой семьи | 20–200 **личных** денег, одно ожидающее предложение на дело. Срок — до конца облавы, максимум 24 ч. После отказа можно предложить снова, если время остаётся и решения по облаве нет |
| `/bribe_decide bribe decision` | Только полицейский, которому адресован конверт | Однократный ответ до срока: принять, отказать или оформить доказательство. Требуется действующая роль полиции и отсутствие отстранения |

Облава старого дела сразу даёт отделу 2 влияния за раскрытие; в «Ночной смене» награда только за фактический перехват. Отмена/взятка не отнимает их.
При продолжении без успешной взятки выручка семьи уменьшается вдвое, отдел получает
ещё 1 влияния и 20 денег. Смена маршрута уменьшает выручку вдвое, но не даёт
дополнительной награды полиции. Отмена возвращает половину оплаченной подготовки.

Взятка резервируется, при отказе/истечении срока возвращается отправителю,
при принятии переходит сотруднику и отменяет облаву. Три подозрения вызывают
служебную проверку и отстранение на 72 ч. Доказательство попытки подкупа даёт
не более одной дополнительной улики на дело, сколько бы раз ни предлагали взятку.

## Районы

| Команда | Кто может | Эффект и ограничения |
| --- | --- | --- |
| `/district_bid district [support] [supply]` | Глава любой стороны, включая полицию | Одна заявка от стороны на розыгрыш, в течение 48 ч. Цена 5 влияния; поддержка +2 влияния, снабжение +60 денег. Максимум два района на сторону |
| `/district_resolve district` | Любой с игровой ролью | Однократное подведение итога после окончания 48 ч |
| `/district_transfer district family` | Глава владельца | Предложение на 24 ч (или до конца владения). Нельзя при открытом розыгрыше и в течение 7 суток после прошлой передачи. Число предложений не ограничено; исполнение одного делает остальные несовместимые предложения недействительными |
| `/district_accept transfer` | Глава стороны-получателя | Один раз по действующему предложению; 3 влияния, лимит двух районов. Срок владения не продлевается, начинается запрет следующей передачи на 7 суток |
| `/district_income` | Любой член стороны-владельца | Один сбор **на сторону в неделю**, по 20 за район в общую кассу; один район не оплачивается дважды за неделю при передаче |

Контроль выдаётся на 21 день. Очки заявки фиксируются при подаче:
до 4 заработанного за неделю влияния +1 за поддержку +1 за снабжение.
При равенстве приоритет у действующего владельца, затем у ранней заявки.
Сбор дохода не требует главы, поскольку деньги всегда идут в общую кассу.

## Еженедельные задания

`/weekly_tasks` доступна организатору с Manage Server/Administrator, ответ личный.
По умолчанию задания публикуются в новостях по понедельникам в 12:00 Europe/Minsk,
с проверкой cron раз в 10 минут. Настройка: `action:schedule day:1 hour:12 minute:0`.
`action:presets` показывает каталог, `action:disable` выключает автоматизацию,
`action:enable` включает со следующего наступления расписания. `action:publish`
ставит задание текущей недели в очередь сейчас, но не создаёт второе за ту же неделю.
Одна работа от стороны, срок — конец воскресенья по Минску. Рекомендованную награду
3 влияния и 20 в кассу организатор подтверждает через `/reward` с ключом из публикации.
Готовые пресеты можно редактировать в таблице Neon `mafia_weekly_task_presets` без деплоя.
Подробности и примеры: `/help topic:weekly`.

## Смена ролей

Роли проверяются при игровом действии, а не непрерывной загрузкой всех участников.
Кошелёк, лимиты подработок и история коррупции остаются у человека. Деньги,
влияние и районы старой семьи остаются у неё. При синхронизации смены стороны
прежнее назначение главы снимается, человек удаляется из незавершённых операций
старой семьи. При расчёте операции роли всех записанных участников запрашиваются
заново, поэтому снятая роль или смена семьи исключает получение награды за старую
сторону. Для потерявшего роль главы организатор назначает замену; при пустом месте
главы его также автоматически занимает первый синхронизированный участник стороны.

Удаление привязки или удаление самой роли отключает участие её носителей при
следующей проверке. При нескольких игровых ролях действия блокируются до
устранения конфликта. Перезапуск для применения роли или привязки не нужен.

## Казино

`/slots amount:5` — слоты, ставка 5–20 личных денег. `/blackjack amount:10` — одна активная раздача с кнопками. `/blackjack_table` — восстановить стол. `/casino_channel channel:#казино` — настройка организатором. Общий лимит: пять игр в день; подробности, вероятности и выплаты: `/help topic:casino`.

## Покушения и аресты

`/plot_start target:@Игрок` — глава, 40 из кассы, 1 покушение семьи в неделю; сбор 24 часа. `/plot_join plot:7` — секретно присоединиться. `/plot_status plot:7` и `/plot_resolve plot:7` — только организатору. На каждого нового участника: 21% утечки цели в новости, затем 25% раскрытия организатора с добавлением 3 улик семье. Успех: 30% + 15 п.п. за участника сверх организатора, максимум 90%; минимум двое. Цель теряет половину личного кошелька и выбывает на 24 часа.

`/evidence` — сводка полиции. `/arrest member:@Игрок` — 4 улики, один заключённый на семью, 24 часа без игровых действий. `/bail member:@Игрок` — глава, 60 из кассы, 50% освобождения, одна попытка. `/cooperate family:cartel` — глава платит 2 влияния за 1 улику против другой преступной семьи, пока свой участник под арестом. Улики не ограничены: заслон «Ночной смены» стоит 2, старая облава — 3, арест — 4. Полные правила: `/help topic:plots` и `/help topic:custody`.

Неудачные `/patrol` и `/investigate` тоже расходуют соответствующую попытку. Вероятность одинакова для всех семей и не зависит от прошлых результатов.

Полицейский `/profile` дополнительно показывает улики по каждой преступной семье, активные дела с подсказками `/raid`, причины недоступности облавы и кандидатов для `/arrest`. Учитываются сроки, защита от повторной облавы, уже назначенные облавы, ранения, аресты и отстранение самого полицейского. Ответ личный, покушения не раскрываются. Участники перечисляются по известным игровым профилям; актуальные роли проверяются при выполнении команды.

## Тайный подрыв влияния

`/sabotage_start family:cartel [beneficiary:mafia]` — глава, 40 из кассы; по умолчанию получатель — своя семья. Одна операция семьи в неделю, сбор 24 часа, 2–12 участников. `/sabotage_join operation:7` — присоединение своей семьи, `/sabotage_status operation:7` и `/sabotage_resolve operation:7` — только организатору. Все ответы личные. Шанс: 60% + 12 п.п. за участника сверх второго − 2 п.п. за очко влияния цели на старте, пределы 10–90%, при одном участнике 0%. Цель и получатель — преступные семьи, разные между собой; цель не может быть своей семьёй.

До срока нет новостей и утечек; внешние действия не изменяют фиксированную защиту цели и число уже записанных вкладов. При успехе переносится до `2 + число участников` влияния, не больше остатка цели и её влияния на старте. При провале с шансом 21% в новости раскрывается семья организатора, без имени и дополнительных улик. После срока итог публикуется в новости. Полные правила: `/help topic:sabotage`; 100 вариантов: [каталог новостей](sabotage-news.md).
